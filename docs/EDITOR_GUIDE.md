# 콘텐츠 편집 안내

감수자를 위한 문서 수정 방법 안내입니다.

## 1. 시작하기

1. 화면의 "로그인" 버튼을 누릅니다.
2. "이메일 주소" 칸에 이메일을 입력하고 "인증 코드 받기"를 누릅니다. 입력한 이메일로 인증 코드가 도착합니다.
3. 받은 인증 코드를 "인증 코드" 칸에 입력하고 "로그인"을 누르면 완료됩니다.

## 2. 문서 수정하기

1. 수정할 문서 페이지에서 "편집" 버튼을 누릅니다.
2. "본문 (마크다운)" 칸에서 내용을 고칩니다.
3. "프리뷰 보기"를 눌러 실제 화면처럼 보이는지 확인합니다. 다시 고치려면 "편집으로 돌아가기"를 누릅니다.
4. 다 고쳤으면 "수정 반영"을 누릅니다.
5. 몇 분 후 문서 페이지를 새로고침하면 수정한 내용이 반영된 것을 확인할 수 있습니다.

## 3. 알아둘 점

- 수정 반영은 즉시 되지 않고 몇 분 정도 걸립니다.
- 같은 문서를 다른 사람과 동시에 고치면 "다른 수정과 충돌했습니다. 아래에 보존된 내 편집본을 참고해 최신 본문에 다시 반영해 주세요." 안내가 뜹니다. 이때 내가 쓴 내용은 화면 아래 "내 편집본 (충돌로 보존됨)" 칸에 그대로 남아 있으니, 그 내용을 참고해 최신 본문에 다시 반영해 주세요.
- 저장하지 않고 화면을 닫아도 괜찮습니다. 같은 문서를 다시 열면 "저장하지 않은 초안이 있습니다"와 함께 "초안 복원" 버튼이 나타납니다.

## 4. 문제 해결

- "편집" 버튼이 보이지 않는다면 로그인이 풀렸거나 편집 권한이 아직 등록되지 않은 상태입니다. 관리자에게 문의해 주세요.
- "시스템 연결에 문제가 있습니다"라는 안내가 뜨면 잠시 후 다시 시도해 보고, 계속되면 관리자에게 알려 주세요.

## 단축키

| 동작 | 단축키 |
|---|---|
| 수정 반영 | Cmd+S (Mac) / Ctrl+S (Windows) |
| 편집 ↔ 프리뷰 전환 | Cmd+E (Mac) / Ctrl+E (Windows) |
