# ① 지원 방향

◦필요 시 학생 지도, 출결 확인 등을 지원할 지원인력을 배치함. 모든 학급 활동, 프로젝트, 체험 학습 등이 접근 가능하도록 기획하여야 함. 특수 교육 보조 장비를 활용하여 필드 트립, 실험, 실습 등의 학급 활동을 지원할 수 있음

◦계획 수립 단계에서는 학급경영 계획 수립을 위한 전문 소프트웨어 및 보조 기기 지원하고, 실행 지원 단계에서는 학급 행사 및 프로그램 실행 시 지원인력 배치하여 장애인교원이 업무를 효율적으로 수행할 수 있도록 지원할 수 있음

| 지원항목     | 지원 내용                                                              | 지원제공자          |
| -------- | ------------------------------------------------------------------ | -------------- |
| 교육 장비 배치 | · 칠판, 프로젝터, 컴퓨터 등 교육 장비를 휠체어 사용자도 쉽게 조작할 수 있도록 배치                  | 학교관리자          |
|          | · 교육 장비의 간단한 이동이나 배치 변경                                            | 지원인력           |
| 교실 가구 배치 | · 이동성을 고려하여 교실 가구를 배치, 필요에 따라 가구를 조정하여 휠체어 등을 사용하는 교원과 학생들의 접근성 향상 | 학교관리자<br/>지원인력 |
