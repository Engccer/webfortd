| 사용 및 지원 방법 | **1. 평지에서 밀기**<br/>▪ 힘 분배: 손잡이를 가볍게 누르면서 양손으로 균등하게 힘을 분배하여 밀어준다. 손목에 너무 무리가 가지 않도록 적절한 힘을 사용하고, 휠체어가 한쪽으로 기울어지지 않도록 균형을 잘 맞춘다.<br/>▪ 속도 조절: 휠체어 사용자의 편안함을 위해 너무 빠르거나 느리지 않게 적절한 속도로 밀어야 한다. 휠체어 사용자가 불편함을 느낄 수 있으니 급하게 움직이지 않는다.<br/>▪ 장애물 주의: 보도블럭, 작은 돌, 구멍 등을 피하도록 주의한다. 휠체어가 흔들리면 사용자가 불편함을 느낄 수 있으므로 길 상태를 주시하면서 이동한다. |
|            | **2. 경사로 오르기**<br/>▪ 몸 가까이 당기기: 경사로를 오를 때는 휠체어를 몸 가까이 당긴 상태에서 두 손으로 밀어준다. 몸을 너무 앞으로 기울이지 않고, 다리를 굽히면서 밀면 더 힘을 효율적으로 사용할 수 있다.<br/>▪ 천천히 밀기: 속도를 너무 빠르게 하지 말고, 일정한 속도로 밀어주어야 한다. 필요 시 중간에 멈추어 잠시 쉬는 것도 가능하다.                                                                                                                 |
|            | **3. 경사로 내리기**<br/>▪ 뒤로 밀기: 경사로를 내려갈 때는 휠체어를 뒤로 밀면서 내려가는 것이 안전하다. 이를 통해 사용자가 경사로의 각도를 더 잘 조절할 수 있습니다. 천천히 밀고, 급격하게 내려가는 것을 방지한다.<br/>▪ 브레이크 사용: 내리막길에서는 휠체어 브레이크를 부분적으로 사용해 속도를 조절하는 것도 중요하다. 경사가 급할 경우 브레이크를 자주 확인하며 내려가는 것이 좋다.                                                                                           |
|            | **4. 턱이나 장애물 넘기**<br/>▪ 앞바퀴 먼저 들기: 턱을 넘을 때는 앞바퀴를 먼저 들어올린 후에 뒷바퀴를 밀어올린다. 휠체어 손잡이를 가볍게 아래로 눌러서 앞바퀴를 들 수 있다. 앞바퀴가 턱을 넘으면 천천히 뒷바퀴를 넘긴다.<br/>▪ 뒤로 넘기기(내리막): 내리막에 있는 턱을 넘을 때는 뒤로 밀어서 뒷바퀴부터 넘습니다. 이때도 천천히 움직이면서 휠체어 사용자가 갑작스럽게 충격을 받지 않도록 주의한다.                                                                                    |
|            | **5. 급정거 및 회전**<br/>▪ 급정거 피하기: 휠체어를 밀다가 갑자기 멈추면 사용자가 앞으로 쏠릴 수 있으므로, 멈출 때는 속도를 천천히 줄이며 멈추는 것이 좋다.<br/>▪ 회전할 때: 회전할 때는 속도를 줄이고, 바깥쪽으로 큰 원을 그리듯이 부드럽게 회전한다. 너무 급하게 돌리면 사용자에게 불편함을 줄 수 있다.                                                                                                                                      |

사용 및 지원 방법
### 6. 브레이크 사용
* 주차할 때 브레이크: 휠체어를 멈출 때나 주차할 때는 항상 브레이크를 사용하여 휠체어가 움직이지 않도록 고정한다. 경사로나 움직임이 있는 환경에서는 특히 중요하다.

☞ 지원인력은 지체·뇌병변장애인교원과 소통하여 휠체어 미는 방법을 충분히 숙지한 후 이동을 지원해야 합니다. 휠체어를 밀 때는 휠체어 사용자와 밀어주는 사람 모두의 안전과 편안함을 고려해야 한다.

사용 및 지원 방법
### 1. 앉고 일어날 때 지원
* 일어날 때: 앉은 상태에서 일어나기 위해서는 워커를 잡지 않고 의자 팔걸이나 좌석을 잡고 몸을 일으켜 세우는 것이 중요하다,
* 앉을 때: 의자에 앉을 때는 먼저 워커를 의자 앞에 두고, 뒤로 넘어가지 않도록 주의해야 한다.

### 2. 계단 사용 지원
* 계단 오르기: 워커는 계단을 오를 때 사용할 수 없으므로, 사용자는 워커를 옆에 둔 상태에서 계단 난간을 잡고 한 발씩 계단을 오르도록 돕는다.
* 계단 내리기: 내려갈 때는 난간을 잘 잡도록 도와주며, 워커는 계단을 다 내려간 후에 사용자가 다시 사용할 수 있도록 한다.

☞ 워커(보행 보조기기)를 사용하는 사람을 지원할 때는 사용자의 안전을 최우선으로 고려하며 적절한 지지와 도움을 제공해야 한다.
☞ 지원인력은 문턱, 경사로. 지면의 장애물이나 미끄러운 정도를 사전에 확인하여 지체·뇌병변장애인 교원에게 안내할 수 있다.
