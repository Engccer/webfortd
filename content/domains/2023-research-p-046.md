# ④ 기타(행정업무 등)

* 고등학교 교원의 교무행정 및 교원인사와 관련한 직무는 [그림 Ⅲ-43]과 같으며, 타당성을 조사한 결과는 <표 Ⅲ-54>와 같음

* 교무행정 및 교원인사 책무와 모든 과업에 대한 타당도가 충족하였음. 과업 및 과업요소에 대한 재구성 의견은 2차 조사 시 반영하였음

| 책무          | 과업                 | 과업요소                                         |
| ----------- | ------------------ | -------------------------------------------- |
| 교무행정 및 교원인사 | 1. 학교 방송실 운영하기     | 학교방송업무, 방송기자재 관리                             |
|             | 2. 교육복지우선지원사업 관리하기 | 학생복지심사위원회, 장학금 업무                            |
|             | 3. 학년부 운영하기        | 학년별 고유 업무 추진                                 |
|             | 4. 교복 학교주관구매 지원하기  | 교복 학교주관구매, 교복선정위원회 조직 및 교복 선정                |
|             | 5. 교육봉사활동 운영하기     | 교육봉사활동 계획 및 운영(멘토링, 교육기부, 특강 등)              |
|             | 6. 교원인사 관리 지원하기    | 교사 포상업무, 교원성과급 업무, 기간제 교사 채용, 초빙교사 채용, 교장공모제 |
